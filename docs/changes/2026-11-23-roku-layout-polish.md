# Roku layout polish

- Home places Continue Watching lower, allowing for the chosen card size.
- Movie pre-play shows more artwork above the details and buttons. Press Down to reach cast and related titles.
- Browse and Collections leave room for the whole focus outline.
- Series episode descriptions wrap to three lines within each card. Hide Spoilers still hides descriptions for unstarted episodes.

The layout follows Arc's other TV apps. No new logging. `npm run check`, `npm test` and `npm run build` passed. Real Roku hardware was not tested.

[Before and after screenshots](2026-11-23-roku-layout-polish/) use brs-engine, a local API fixture, and generated artwork.
