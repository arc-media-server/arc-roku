# Honor Season posters on Roku Home

Roku now uses the season poster for an individual episode on Home rows configured to show Season posters. This includes Continue Watching, Up Next, Recently Added in a TV library, and playlist shelves. If an episode has no season poster, it falls back to the show poster when available. The profile's spoiler preference still hides episode stills and summaries. Thumbnail and Backdrop views retain their wide artwork.

Grouped Recently Added season cards keep their season posters by default and follow an explicit Show posters choice. This matches Arc's Home settings on the web and uses the existing item artwork fields and row preferences.
