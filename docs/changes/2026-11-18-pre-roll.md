# Pre-roll before initial playback

Initial player attempts fetch the server-selected pre-roll list before starting film setup. The
server filters episodes/home videos. Resume, extras, Watch Together and queue replacements
bypass the list. A three-second native Timer is independent of the API Task; empty/failed lists
or timeout fall through, and late replies cannot restart clips. Existing bottom-right Skip is
the sole action during clips: OK advances once and Back exits the attempt.

Use the existing Video node and API Task. Each clip URL is exchanged through `/api/v1/cast`;
server arc-media-server/arc-media-server#485 is required. Old cast responses are rejected by clip
index/phase and closed-player checks. Clips keep movie progress/queue setup inactive. Native
finished/error states advance; ordinary movie startup begins only after the clips are exhausted.
No new settings or screen type. Reuse the identical catalog XML comment fix from Roku #19/#20.
